# 🚀 NeuroTrade — Smart Trading & Financial Assistant

NeuroTrade is a modern **full-stack fintech web application** designed to help users trade smarter, manage finances, and build financial discipline.

Built with a **futuristic UI**, real-time market data, and interactive financial tools, NeuroTrade aims to simplify trading and financial decision-making for beginners.

---

## 🌟 Features

### 📈 Live Market Dashboard

* Real-time stock data using Yahoo Finance API
* Top gainers & losers
* Clean, responsive trading UI

### 💼 Virtual CA (Financial Assistant)

* Tax Calculator 💰
* Savings Analyzer 📊
* Goal Planner 🎯
* Smart financial tips

### 🔐 Authentication System

* Login / Signup functionality
* Local storage-based session handling

### 🧠 Smart UI/UX

* Dark theme with neon accents (#0ecb81)
* Glassmorphism design
* Smooth animations and transitions

### 🧾 News Integration

* Latest financial news updates
* Market insights

---

## 🛠️ Tech Stack

### Frontend

* HTML5
* CSS3 (Glassmorphism + Responsive Design)
* JavaScript (Vanilla JS)

### Backend

* Node.js
* Express.js

### APIs

* yahoo-finance2 (for stock data)

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/your-username/neurotrade.git
cd neurotrade
```

### 2️⃣ Install dependencies

```
npm install
```

### 3️⃣ Run the server

```
node server.js
```

### 4️⃣ Open in browser

```
http://localhost:3000
```

## 🎯 How It Works

* Backend fetches stock data using Yahoo Finance API
* Frontend dynamically renders data on the market page
* Virtual CA provides financial tools and guidance
* Navbar & Footer are reusable components across pages
